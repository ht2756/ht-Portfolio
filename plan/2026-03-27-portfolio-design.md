## 一、项目定位

### 一句话
一个混搭风格的个人独立站，全栈开发者（HT）和 UI 设计师（太太）各自拥有专属展区，同时集成 AI 实验室和学习成长记录，每个板块视觉风格独立鲜明。

### 核心受众
- **现阶段**：展示和自我表达为主
- **后期**：逐步加入求职和接单能力

### 站名
**HT Lab** — 专业、简洁、探索感

## 二、板块规划

| 板块 | 内容 | 风格方向 | 色调 | 面向受众 |
|------|------|----------|------|----------|
| **首页 (Home)** | 品牌入口 + 滚动叙事引导 | 终端加载 → 电影感叙事 | 暗色 → 亮色渐变过渡 | 所有人 |
| **Dev Zone（HT 的区）** | B端项目/小程序作品集、技术笔记 | 暗色仪表盘 + Geek 感 | 深色（深蓝/深灰） | 技术同行/HR |

## 三、导航模式

首页采用 **Hub + 滚动叙事** 混合模式：
1. **首屏**：终端/代码风格的加载动画 → 打字机效果「正在加载 HT Universe...」
2. **加载完成**：切换到电影感的品牌展示 + 个人简介
3. **向下滚动**：依次「遇见」各板块的预告卡片（每张卡片是该板块风格的微缩版）
4. **点击卡片**：进入对应板块，体验完全独立
5. **全局导航**：顶部固定导航栏，可在各板块间快速切换

## 四、技术架构

### 核心原则
**前端为主、后端最小化**

| 层 | 方案 | 说明 |
|---|------|------|
| **前端框架** | Next.js (App Router) | SSR/SSG、SEO 友好、React 生态 |
| **UI 组件** | Tailwind CSS + Framer Motion + GSAP | Tailwind 样式 + Framer Motion 组件动效 + GSAP 滚动叙事 |
| **后端** | Spring Boot（轻量） | 只负责动态能力部分 |
| **数据库** | MySQL（阿里云 RDS） | 本地开发用本地 MySQL |
| **AI** | Dify API 对接 | 前端/后端均可直调 |
| **内容管理** | Markdown + Next.js SSG | 作品、笔记等用 MD 文件管理 |
| **PPT 生成** | 构建时脚本生成静态页 | CI/CD 中自动转换，方便后续批量添加 |
| **部署** | 前端：Vercel / 后端：阿里云 ECS | 各自独立部署 |
| **代码规范** | 阿里巴巴 Java 开发手册 / 前端规范 | 后端遵循阿里标准规范 |
| **多语言** | next-intl / 自定义 i18n | 中/英文切换 |
| **主题切换** | Dark/Light Mode | CSS Variables + context，首页支持顺滑切换 |

### 前后端分离
- 前端和后端独立开发、独立部署
- 后端只介入需要动态能力的场景：
  - Dify AI 对接（API 代理/鉴权）
  - 联系表单/留言（未来）
  - 需要数据库的动态功能（未来接单系统等）
- 大部分页面静态生成，后端压力极小

### 5.1 首页（Home） ✅

**风格定位：终端加载 + 电影感叙事**

**交互流程：**
1. 打开网站 → 黑色背景，绿色文字逐行打出终端命令
   ```

   > loading modules...
   > connecting to portfolio...
   > ✓ all systems online
   ```

2. 终端「启动完成」→ 全屏过渡动画（类似电影片头的淡入/缩放）

## 九、开发阶段技术方案（待视觉稿确认后展开）

### 前端项目结构（初步）
```
ui/
├── src/
│   ├── app/                    # Next.js App Router
│   │   ├── page.tsx            # 首页
│   │   ├── dev/                # Dev Zone
│   │   ├── design/             # Design Zone
│   │   │   ├── page.tsx        # PPT 列表页
│   │   │   └── [slug]/         # PPT 详情页（SSG）
│   │   ├── ai/                 # AI Lab
│   │   └── growth/             # Growth Log
│   ├── components/             # 共享组件
│   ├── content/                # Markdown 内容
│   └── styles/                 # 全局样式
└── public/                     # 静态资源
```

### 后端项目结构（初步）
```
workspace/
├── src/main/java/
│   ├── controller/             # API 控制器
│   ├── service/                # 业务逻辑
│   ├── config/                 # 配置（阿里云、数据库等）
│   └── util/                   # 工具类
└── src/main/resources/
    ├── application.yml         # 应用配置
    └── mapper/                 # MyBatis Mapper
```
